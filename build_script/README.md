# Signline `v0.1.0b` — Native Debian (`.deb`) Package & Ratatui TUI Installer

This directory (`build_script/`) contains everything needed to compile, package, and install Signline `v0.1.0b` natively on Debian/Ubuntu Linux as a standalone `.deb` package with an interactive **Ratatui TUI Installer**.

---

## Contents of `build_script/`

```text
build_script/
├── build_deb.sh         # Automated dependency checker, compiler & .deb packager
├── build.sh             # Alias for build_deb.sh
├── install_deb.sh       # Compiles (if needed) and installs the .deb via dpkg
├── tui-installer/       # Source code for the Ratatui TUI installer (/usr/bin/signline-installer)
│   ├── Cargo.toml
│   └── src/main.rs
└── dist/
    └── signline_0.1.0b_amd64.deb   # Compiled Debian package (generated by build_deb.sh)
```

---

## 1. Compile the `.deb` Package from Source

Run from the repository root (or inside `build_script/`):

```bash
./build_script/build_deb.sh
```

What `build_deb.sh` does automatically:
1. **Checks System Dependencies**: Verifies `build-essential`, `pkg-config`, `libssl-dev`, `curl`, `unzip`, `dpkg-dev`, `poppler-utils`, `nodejs`, `npm`, `rustc`/`cargo`, and `pocketbase` (`v0.25.9`), requesting `sudo` privileges to install any missing packages.
2. **Builds the Frontend**: Compiles the TypeScript + React 18 + ShadCN/UI production bundle (`frontend/dist`).
3. **Compiles the Rust Backend**: Builds `signline-backend` (`/usr/bin/signline-server`).
4. **Compiles the Ratatui TUI Installer**: Builds `signline-installer` (`/usr/bin/signline-installer`) from `build_script/tui-installer/`.
5. **Packages the `.deb` Archive**: Produces `build_script/dist/signline_0.1.0b_amd64.deb` containing:
   - `/usr/bin/signline-server` (Rust backend server)
   - `/usr/bin/signline-installer` (Interactive Ratatui TUI setup wizard)
   - `/usr/lib/signline/bin/pocketbase` (Embedded PocketBase daemon)
   - `/usr/share/signline/frontend/dist` & `/usr/share/signline/public` (Compiled frontend SPA & brand assets)
   - `/lib/systemd/system/signline.service` (Systemd service unit)
   - `DEBIAN/postinst` (Automatically launches the Ratatui TUI installer on interactive terminals during `dpkg -i` / `apt install`)

---

## 2. Install the `.deb` Package

To compile (if not already built) and install in one step:

```bash
./build_script/install_deb.sh
```

Or install the compiled `.deb` directly with `dpkg` or `apt`:

```bash
sudo dpkg -i build_script/dist/signline_0.1.0b_amd64.deb
```

You can also re-run the interactive **Ratatui TUI Installer** at any time after installation:

```bash
sudo signline-installer
```
